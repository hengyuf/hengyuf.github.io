2D attention on a three-scale pretraining ladder

“2D attention” lets the later layers of a transformer reuse the keys and values of earlier layers. This page records every officially tested variant on a three-scale pretraining ladder of MoE transformer language models with hybrid full + sliding-window attention: d512 (6 blocks), d768 (8 blocks) and d1024 (11 blocks). An official test is nine training runs (every scale at the learning-rate multipliers 0.8, 0.9 and 1.0, everything else fixed), judged by the final Paloma macro loss at equal training steps; the aim is a gain over the baseline that holds as the model gets larger.

Score. score = 0.25 × (L_base_512 − L_512) + 0.25 × (L_base_768 − L_768) + 0.5 × (L_base_1024 − L_1024), where L_d is the best final Paloma macro loss over the three learning-rate multipliers at scale d and L_base_d is the baseline's. Higher is better.

ref2DOriginal 2D attention (window 2048)+0.0073

A later full-attention block attends, in one softmax, over its own keys and the cached keys / values of every earlier full-attention block within the last 2048 tokens.

reference row

The starting point of the project. By the project's definitions it is a family-A mechanism: it reuses the cached key / value tensors of earlier layers directly.

What changes, and what comes from each parent

Every full-attention block after the first becomes a query block: block 5 reads block 3 at d512, block 7 reads block 3 at d768, and at d1024 block 7 reads block 3 and block 10 reads blocks 3 and 7. The cached keys and values of the source blocks, within a lag window of 2048 tokens, join the query block's own keys and values in a single softmax. No parameters are added.

Evolved from

  • baseline: The whole model; the later full-attention blocks get the cached keys / values of the earlier full-attention blocks as extra keys.
Why it was tested

It is the method the project sets out to improve. Its gain shrinks with model size and is gone at d1024, which carries half of the score. In the diagnosis the cached keys take most of the query block's attention and crowd out its own long-range attention.

Implementation

For a query at token s of a query block there is one softmax over the block's own keys at positions i ≤ s and, for each source block, that block's cached keys at positions s − 2048 < i ≤ s of the same document; the values are gathered the same way and the caches stay differentiable. Source map (query block: source blocks): d512 {5: 3}, d768 {7: 3}, d1024 {7: 3, 10: 3 and 7}. No new parameters.

  • attention of query block q at token s: softmax over { own keys, i ≤ s } ∪ { cached keys of each earlier full-attention block, s − 2048 < i ≤ s }

At initialisation. No new parameters; the extra keys take part in the softmax from the first step.

refAttnResAttnRes Full (reference; not a 2D method)+0.0216

Every sublayer reads a learned per-token softmax mix of all earlier sublayer outputs instead of the residual stream.

reference row

Not a 2D method. It is the bar to beat and the host of family C.

What changes, and what comes from each parent

The input of every sublayer (attention and MoE) and of the final norm is a depth mix over the token embedding and all earlier sublayer outputs. Q, K and V of a block share one mix. There is no residual stream besides these mixes.

Evolved from

  • baseline: The blocks with their norms and projections; the residual stream is replaced by learned depth mixes.

Later methods built on it: ar3, arfy

Why it was tested

A different mechanism (Attention Residuals), run before the project as a reference. It keeps most of its gain at d1024 and is the bar to beat for the 2D variants.

Implementation

Sources: o_0 = the token embedding, then the output of every attention and MoE sublayer. Each sublayer reads the weighted mean sum_i alpha_i · o_i of all earlier sources, alpha_i = softmax_i(w · rmsnorm(o_i)), and applies its unchanged norm and branch to it; the first sublayer reads the embedding itself. A final mix over all 2L + 1 sources feeds the final norm. That makes 2L + 1 mixes (13 / 17 / 23 at d512 / d768 / d1024), each with two vectors of size d.

  • alpha_i = softmax_i(w_j · rmsnorm(o_i)) over every source o_i before sublayer j
  • input of sublayer j = sum_i alpha_i · o_i

At initialisation. Every mix starts as the uniform average of its sources (query vectors at zero).

#1YOCOthe upper blocks take K/V from the mid-depth stream+0.0114

The blocks above the middle of the network compute their keys and values from the stream that enters the middle block instead of from their own input.

official test 1completed 2026-11-10family B: K/V (or Q) built from earlier layers' outputschange to the plain baseline

A fixed (not learned) choice of the depth that feeds K and V; an existing method, used here as the routing the later variants build on.

What changes, and what comes from each parent

Let m be the middle block and z the residual stream entering it. Every block above m still forms its queries from its own input, but computes its keys and values from z, through its own norm and its own K / V projections. Nothing is added to the softmax and no parameters are added or removed. The official row uses the middle block 3 of 6 at d512, 4 of 8 at d768 and 5 of 11 at d1024.

Evolved from

  • baseline: The whole model; only the K / V input of the blocks above the middle block is re-wired.

Related ideas (not parents; not drawn in the forest)

  • 2D: It replaces the K/V input where the original 2D adds keys to the softmax.

Later methods built on it: yvg, kvrz, yq, arfy

Why it was tested

It is the strict form of "later layers reuse earlier layers' K/V" and the closest existing relative (You Only Cache Once) of the variants planned in the project. The original 2D adds the earlier layer's keys to the softmax next to the layer's own keys, where they crowd out distant tokens; YOCO replaces the K/V input instead of adding keys, so it shows whether strict reuse keeps a gain at d1024 where the original 2D keeps none.

Implementation

Blocks 0 .. m are baseline blocks. In every block l > m the queries come from the block's own stream and the keys and values from z = h_m, through block l's own norm and projections. Routed blocks: 4 and 5 at d512 (m = 3), 5 to 7 at d768 (m = 4), 6 to 10 at d1024 (m = 5). No new parameters.

  • z = h_m (the stream entering the middle block m)
  • for l > m: Q = W_Q · norm_l(h_l), K = W_K · norm_l(z), V = W_V · norm_l(z)

At initialisation. No new parameters; a fixed re-wiring (it differs from the baseline from the first step).

#2kvrone learned depth mix shared by K and V+0.0042

In every block after the first, keys and values are computed from one learned per-token mix of all earlier sublayer outputs instead of from the block's input stream.

official test 2completed 2026-11-10family B: K/V (or Q) built from earlier layers' outputschange to the plain baseline

What changes, and what comes from each parent

In every block after the first, the K and V projections no longer take the block's input stream. They take one learned, per-token softmax mix of the outputs of all earlier sublayers (the token embedding and every earlier attention and MoE output). K and V share the mix. Q, the MoE sublayer and everything else are unchanged. At initialisation the mix equals the stream, so the model starts as the baseline.

Evolved from

  • baseline: The whole model; only the input of the K and V projections changes.

Related ideas (not parents; not drawn in the forest)

  • AttnRes: The per-token depth mix is AttnRes's read, applied to the K/V input only.
  • YOCO: "A soft YOCO in every layer": the depth that feeds K/V is learned instead of hard-wired.
  • 2D: A factorized form of the 2D idea: instead of adding earlier layers' keys to the softmax of one or two layers, depth is mixed per token before the K/V projection, in every layer.

Later methods built on it: qkvr, kvrz

Why it was tested

YOCO hard-wires which earlier stream the upper blocks reuse for K/V; AttnRes Full learns a depth mix for every sublayer input. kvr is the smallest step between the two: only K/V get a learned depth mix, in every block ("a soft YOCO in every layer"). It tests whether learned K/V reuse alone keeps a gain at d1024.

Implementation

Blocks 1 .. L − 1 each get one depth mix S_l over the sources o_0 .. o_2l, anchored at the block's own stream. K and V are the block's own projections of norm_l(S_l); Q stays the projection of norm_l(h_l). One mix per block (5 / 7 / 10 mixes), two vectors of size d per mix.

What changes, and what comes from each parent

AttnRes Full feeds every sublayer a learned per-token depth mix of all earlier sublayer outputs, and its attention sublayer projects Q, K and V from one mix. arfy keeps all of that up to the middle block m (block 4 of 6 at d512, 5 of 8 at d768, 6 of 11 at d1024). In the blocks above m the queries still come from the block's own depth mix, but K and V are projected from z, the stream entering block m, through the block's own norms and projections: YOCO's routing on the AttnRes stream. AttnRes Full has no residual stream, so z is formed as the plain, unweighted sum of the token embedding and of the outputs of all sublayers of the blocks below m, which is what the residual stream holds at that depth on the plain baseline. The MoE inputs and the final output are AttnRes Full's. No parameter is added to AttnRes Full's.

Merged from

What changes, and what comes from each parent

arfy (AttnRes Full with YOCO's routing above the middle block m; m = 4 / 5 / 6 at d512 / d768 / d1024) plus the output gate. Block 0 and the first full-attention block (block 3) publish their value tensors. Every later block adds them to the output of its attention sublayer: block 0's values in every block after the first, and block 3's values as well in the blocks above block 3. The values are taken at the token's own position, so the new term involves no attention over positions. Each is scaled by a gate: one number per token and query head, a linear function of the block's normalised query input. All gate weights start at zero, so the model starts as arfy. Q, K, V and the softmax are arfy's. The sources are those of vgate: vgate adds them to the block's values before attention, the output gate adds them to the output of the attention.

Evolved from

  • arfy: Everything: AttnRes Full with YOCO's routing above the middle block (4 / 5 / 6). Only the output gate is added, in every block after the first.

Related ideas (not parents; not drawn in the forest)

  • vgate: The output gate reads vgate's sources (the cached values of block 0 and of the first full-attention block) through the same kind of per-token gate, but adds them to the output of the attention instead of to the block's values.
  • ar3y: The other addition to arfy that was tested officially (learned K and V mixes below the routing). The results log compares the three rows arfy, ar3y and arfyo at every scale.
Why it was tested

On the plain baseline the output gate lowered the d1024 loss in two single runs at LR 0.9, each against the same method at the same middle block without the gate: from 2.98596 to 2.98321 on yqg (middle block 6), and from 2.98121 to 2.97889 on yqg with a gain of 2 on the query mix (middle block 7, which is not the block of the official row yqgx2). d1024 is also the scale where arfy gains least over the baseline (0.0291, against 0.0426 at d768).

Implementation

Host: arfy, unchanged (AttnRes Full's weighted-mean mixes; in the blocks above m, K and V are the block's own projections of norm_l(z), where z is the plain sum of the sources that the attention sublayer of block m sees). Consumers: blocks 1 .. L − 1. Sources: block 0 for every consumer, plus block 3 for the blocks above it: 7 / 11 / 17 (consumer, source) pairs at d512 / d768 / d1024, the pairs of vgate. A source publishes its own values, V = W_V · norm(mix); both sources lie below the middle block, so these are AttnRes Full's values. In a consumer, attention runs as in arfy and gives one output vector y per query head (after the removal of the component along the token's own value, as in the baseline). The gate of a pair is a linear map of the block's normalised attention mix, the input of the query projection, to one number per query head, with d weights and one bias per query head, all zero at initialisation. The gated values of the same token are added to y (a query head reads the source's KV head it is grouped with); the block's head gate and output projection are then applied to the sum, as in the baseline. The term has no mask and no positional encoding, and gradients flow through it. New parameters on top of AttnRes Full's mixes: the gates only, 14,364 / 50,754 / 139,400.

  • omega_s(t, n) = a(t) · U_s + e_s (one number per token and query head; a = norm_l(mix_l), the block's normalised query input)
  • y'(t, n) = y(t, n) + sum_s omega_s(t, n) · v_s(t, g(n)), s = block 0, and block 3 for blocks above it (y = the output of attention for query head n; g(n) = the KV head that query head n uses)
  • the block's head gate and output projection are applied to y'; Q, K, V and the softmax as arfy

At initialisation. Equals arfy (same middle block) at initialisation: all gate weights and biases are zero. In the short test runs made before the official ones, the first training losses of the two agreed to 3e-6 at each scale; in the official runs they differ by no more than two runs of the same method do (the rounding of single-precision arithmetic).

How these operations are counted
  • depth mixes feeding Q / K / V. Depth mixes that feed Q / K / V: per token a softmax over the n earlier sublayer outputs from one learned vector per mix, then the weighted sum. R mixes of one block share one pass: n(2D+2) + R n(4D+5) on the residual stream; n(2D+2) + R((4n-1)D + 3n) on the AttnRes stream.
  • depth mixes feeding the MoE sublayers and the final norm. AttnRes stream only: the depth mix in front of every MoE sublayer (n = 2i+2 sources) and the final one (n = 2L+1): (6n-1)D + 5n each.
  • extra pre-norms. The block's own attention pre-norms (RMS norm + rank-128 gated norm) applied to one more input stream: a K / V depth mix, the residual stream next to a Q mix, or the mid-depth stream of the YOCO routing. P = 4*128*D + 8D + 514 per stream and block. The K / V projections themselves keep their size.

  • building the mid-depth stream. AttnRes stream with YOCO routing: building the mid-depth stream (the sum of 2m+1 sources, or one more depth mix over them).
  • residual adds that no longer exist. AttnRes stream: the two residual adds per block of the baseline do not exist (-2LD).

How to read this

Setup
A research log on variants of "2D attention" (later layers of a transformer reuse the keys / values of earlier layers) on a three-scale pretraining ladder of MoE transformer language models with hybrid full + sliding-window attention: d512 (6 blocks), d768 (8 blocks) and d1024 (11 blocks). The aim is a gain that holds as the model gets larger. An official test of a method is 9 training runs: the three scales, each at learning-rate multipliers 0.8, 0.9 and 1.0, with the MoE architecture, the optimizer, the attention layout and the training data fixed. Evaluation: the final Paloma macro loss (mean of the 16 per-set losses; lower is better). All comparisons are at equal training steps.
Official test
One method, nine training runs: d512, d768 and d1024, each at the learning-rate multipliers 0.8, 0.9 and 1.0, with everything else fixed. For each scale the best final loss over the learning rates is taken; its distance below the baseline's best is the gain at that scale (“base − best”), and the score is the weighted sum of the gains (weights 0.25 / 0.25 / 0.5), so the largest model counts most. The x axis of both charts is the order in which the official tests were completed. “Best so far” in the score chart counts the changes to the plain baseline only; a method stacked on AttnRes Full is to be compared with the AttnRes Full line.

FLOPs
FLOPs are counted analytically per token of a forward pass with the training code's own convention: a linear map with n weights costs 2n, and attention is counted as a full map of every query against all 8,192 key slots in every block; training is taken as 3 × forward, so a ratio of forward FLOPs is the ratio of training FLOPs. The operations a method adds are counted more completely than the baseline itself (norms and element-wise operations included), so every ratio is an upper bound, while data movement counts as zero. FLOPs understate the cost of these methods. A depth mix reads every earlier sublayer output of the network once more per block: almost no arithmetic, but many passes over large tensors, which the hardware pays for in memory traffic. Measured step time is the better guide to cost: it is listed in each method's panel.
The counting convention
  • The baseline number is the training code's own analytic count (the value every run logs as its analytic FLOPs per token), reproduced term by term.
  • A linear map with n weights costs 2n FLOPs per token (one multiply and one add per weight).
  • Attention is counted as a full map: every query against S = 8192 key slots in every block - QK^T (2 per slot, head and head dim), masking + softmax (3 per slot and head), the AV product (2 per slot, head and head dim). The sliding-window blocks (window 2048) are counted with 8192 slots like the full-attention blocks; there is no causal or window discount.
  • The numbers are forward FLOPs per token. The code takes training = 3 x forward (the backward pass as 2 x the forward), so a ratio of forward FLOPs is the ratio of training FLOPs.
  • Extra terms are counted more completely than the baseline: linear maps at 2 per weight and a softmax entry at 3, as in the baseline, plus every other scalar operation at 1 (norms, activations, biases, element-wise scales and adds), which the baseline count leaves out of the baseline itself. Every excess is therefore an upper bound: counted with the baseline's own rule the extra term is 2.8-17.7 % smaller for the methods with depth mixes; at most 1.7 % smaller for the methods without one; 33 % smaller for AttnRes Full, whose extra term is depth mixes only. Data movement (casts, gathers, caches kept across blocks) costs 0.
Every ratio to the baseline on this page, FLOPs and step time alike, is printed with three decimals; the excess in percent and the FLOPs per token in each method's panel carry the finer detail.
Step time
Step-time ratio = the method's time per optimizer step (median over the three runs of the official test at that scale) divided by the baseline's at the same scale (same batch, sequence length, number of steps, device layout and run options). Scores are at equal training steps, not equal time.
Families
  • A: reuse of earlier K/V tensors. The method reuses the key / value tensors of earlier layers directly.
  • B: K/V (or Q) built from earlier layers' outputs. The method builds a layer's keys / values (in later variants also its queries) from the outputs of earlier layers: a learned per-token depth mix, or, for YOCO, a fixed earlier stream.
  • A+B. Both kinds of change in one model.
  • C: stacked on AttnRes Full. The change is made on top of AttnRes Full instead of the plain baseline; reported separately from A and B.
  • reference. Rows from earlier campaigns (same data and recipe): the yardstick and the starting points.

Glossary of the terms used in the method panels
block
Block l (0-based) is an attention sublayer followed by an MoE sublayer. h_l is the residual stream entering block l: the token embedding plus the outputs of all earlier sublayers. The baseline computes Q, K and V of block l from norm_l(h_l) with the block's own projections W_Q, W_K, W_V.
full-attention block
Block i is a full-attention block (full causal attention, no positional encoding) if i mod 4 = 3 or it is the last block: blocks 3 and 5 at d512, 3 and 7 at d768, 3, 7 and 10 at d1024. Every other block attends within a sliding window of 2048 tokens.
depth mix
The sources o_0 .. o_2l are the token embedding and the output of every earlier attention and MoE sublayer (N = 2l + 1 sources for the attention sublayer of block l). One learned vector u gives per-token weights alpha_i = softmax_i(u · rmsnorm(o_i)). On the plain baseline the mix is S = h_l + N · sum_i (alpha_i − 1/N) · o_i, so with u = 0 it is exactly h_l and the model starts as the baseline. Each mix adds two vectors of size d (u, initialised at zero, and a norm gain, initialised at one). AttnRes Full uses the plain weighted mean sum_i alpha_i · o_i and has no residual stream.
middle stream (YOCO routing)
m is the middle block and z = h_m the residual stream entering it. A routed block (every block above m) still forms its queries from its own input, but computes K and V from z through its own norm and its own K / V projections. On AttnRes Full, which has no residual stream, z is the plain sum of the sources that the attention sublayer of block m sees (the token embedding and the outputs of all sublayers of the blocks below m): the same formula as h_m.
value gate
v'(t) = v(t) + sum_s gamma_s(t) · v_s(t). The v_s are the cached value tensors of the source blocks s (block 0, and block 3, the first full-attention block, for the blocks above it); gamma_s(t) = a(t) · W_s + c_s is one number per token and KV head, a linear function of the block's normalised input a(t). W_s and c_s start at zero. Attention then runs with (k, v'); no softmax is added or changed.
output gate
y'(t, n) = y(t, n) + sum_s omega_s(t, n) · v_s(t, g(n)). y(t, n) is the output of a block's attention for token t and query head n, before the block's head gate and output projection. The v_s are the cached value tensors of the source blocks s (block 0, and block 3, the first full-attention block, for the blocks above it), read at the same token t; g(n) is the KV head that query head n uses. omega_s(t, n) = a(t) · U_s + e_s is one number per token and query head, a linear function of the block's normalised query input a(t). U_s and e_s start at zero. The term reads no other position: no softmax is added or changed. The value gate adds the same sources to the block's values before attention; the output gate adds them after it.
mix gain
A constant g on the logits of a depth mix: alpha_i = softmax_i(g · u · rmsnorm(o_i)). With u = 0 the weights are uniform for any g; it equals a g-times larger learning rate on u.
